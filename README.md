# Niccolo Bressler — Portfolio source files

## Files
- index.html: all visible text, project descriptions, sections, and links.
- style.css: colors, typography, spacing, and responsive layouts.
- script.js: the 3D Canvas animation, controls, and copy-email action.

## Change the text
1. Extract the ZIP and open the folder in VS Code or another text editor.
2. Open index.html and search for the text you want to change.
3. Edit the words between HTML tags, preserving the tags and their attributes.
4. Save, then open index.html in a browser and refresh to see changes.

The HTML and CSS use compact formatting. In VS Code, right-click in a file
and choose Format Document if you prefer an expanded layout.

## Preview
Double-click index.html for a quick preview. This download uses relative
asset links so the stylesheet and script load beside the HTML file.
No package installation or build step is required.

For a local web-server preview, run this from the extracted folder:

    python -m http.server 8000

Then visit http://localhost:8000. On some systems use python3 instead of python.
The copy-email feature depends on browser clipboard permissions and is best
checked on localhost or HTTPS.
