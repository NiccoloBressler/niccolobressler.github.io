Front-end engineering

This portfolio uses semantic HTML, responsive CSS, and vanilla JavaScript. A custom Canvas renderer displays the interactive 3D wireframe.

HTML5CSS3JavaScriptCanvas API
Technical details +

A custom renderer projects 3D geometry onto a 2D canvas, with mouse, touch, and keyboard controls—built without a 3D library.

  • CSS Grid, Flexbox, and media queries adapt the layout to desktop and mobile screens.
  • Animation uses requestAnimationFrame and pauses when offscreen or when the tab is hidden.
  • Reduced-motion support, keyboard navigation, and semantic HTML keep the experience accessible.
  • Static assets and a capped canvas pixel ratio keep downloads small and rendering work bounded.
